# Protocol issues: run_A

Places where the protocol was ambiguous or could not be followed literally, with what this run did. Ordered roughly by how much they could make runs differ.

| # | Step | What was unclear | What I did |
|---|------|------------------|------------|
| 1 | ROW (TiR) | TiR is read "from the dataset", but the Brightway import of ecoinvent 3.12 has no time-period / start-end date fields, and the dataset comments carry no year. | Logged TiR as unclear and set TiR = 5 (the conservative value) for every row, so DQR is high for everything. **Fix:** give a source for the time period (e.g. the ecoSpold files or a lookup table), or a default TiR for ecoinvent 3.12. |
| 2 | D1–D4 for transport | Which lorry is "lorry"? RER has 17 lorry markets (the unspecified one plus size × EURO-class variants). Read literally, D4's "else first A–Z" would pick `lorry, 16-32 metric ton, diesel, EURO 3`. | Treated `market for transport, freight, lorry, unspecified` (RER) as the D1 exact match for an unspecified lorry, so D4 never ran. **Fix:** name the lorry and ship datasets in the protocol. |
| 3 | S1 | (a) EPDs often give ranges ("3–4.5 %", "20–55 %"), not values. (b) The medians of several EPDs, taken per constituent, do not sum to 1. (c) The protocol does not say whether "ÖKOBAUDAT, then EPD registries" means stopping at ÖKOBAUDAT when it has an EPD with a composition. | (a) Took the midpoint of each range and, where it applied, made wood the remainder. (b) Normalised the medians to sum to 1 (OSB: 1.0029 → 1). (c) Stopped at ÖKOBAUDAT-listed EPDs (OSB: 3 IBU EPDs; hempcrete: 1). For cork, ÖKOBAUDAT had only a generic dataset with no composition, so I went to EPD Hub. |
| 4 | S1, hempcrete | The only EPD gives hemp 20–55 % and binder 45–80 %, a very wide range that drives the EPD check result. Mixing water and equilibrium moisture (dry 335 kg/m³ vs. 405 kg/m³ delivered) are not split out. | Used the midpoints 0.375 / 0.625 as delivered. Water is counted inside the shares, as the EPD says. |
| 5 | D5 | "Check whether its raw materials and processing steps exist in ecoinvent." ecoinvent seldom has processing-only datasets (mixing, pressing, autoclaving), so it is unclear whether energy carriers taken from an analogous ecoinvent dataset count. | Hempcrete: **yes**. The EPD says the blocks are made on a concrete-block forming plant, so I used the electricity and diesel per kg from `concrete block production` DE. Cork: **unclear → D6**. There is no autoclave/steam-expansion data, and the conservative branch is the resin-bonded cork slab. Another run could reasonably build cork from `cork, raw` plus heat. **Fix:** say whether an analogous ecoinvent dataset's energy may stand in for the route source. |
| 6 | D5 → D1 (TeR) | For a built material, it is unclear whether each constituent row gets the TeR of its own D1 result (e.g. 1) or TeR 3 ("D5 built"). | Gave all A1–A3 rows of the built material TeR = 3. |
| 7 | D2 for waste treatments | "Market first" doesn't fit end-of-life rows. `market group for waste wood, untreated` is a mix of treatment routes, but C3–C4 needs one row per route. | Used the specific treatment activities, logged as D1/D3/D6. **Fix:** state that D2 is skipped for C3–C4 and A5 end-of-life rows. |
| 8 | C3–C4 recycling | Under cut-off, wood recycling in ecoinvent (`treatment of waste wood, post-consumer, sorting and shredding`) has wood chips (dry mass) as its reference product. It is not a waste treatment with a negative amount, unlike the brick example. | Wrote it as a positive input (dry mass = share × 581.7/607), so the shredding burden sits in C3. **Fix:** say whether recycling rows are written at all and with what sign. |
| 9 | C2 · E1, hempcrete | Hemp-lime blocks are "masonry" (category 8: 99 % recycling), but the producer's EPD says they cannot be landfilled and goes to incineration. The heaviest-constituent rule (lime binder) also leads to a mineral category. | Category 8, logged as a direct match by product type (masonry). The EoL datasets are concrete proxies (TeR 5). This is likely to differ between runs. |
| 10 | C2 · E1, cork | The product is an insulation board (EN 13170) but the function is rainscreen cladding. "The product type it is used as" could point to a cladding category, which NMD's list here does not have. | Category 52, organic/bio-based insulation. No cork waste treatment exists in ecoinvent, so I used waste wood treatments as a D6 proxy (TeR 5). |
| 11 | A5 · I1 / C1 · X1 piece weight | "Typical piece" is not defined when a product comes in many sizes (OSB 6–40 mm, up to 1250 × 6250 mm = 187 kg). | Took the format typical for the screened function (OSB T&G floor board 2500 × 675 × 22 mm = 22.7 kg) and logged the alternative. |
| 12 | C1 · X1, OSB floor deck | Floor decks are glued at the T&G joints and screwed. Does a glued joint count as "bonded"? | Yes → diesel row. The result depends on the function: as roof sheathing it would be "no". |
| 13 | C1 · X1, cork rainscreen | The maker lists both adhesive and mechanical fixing. A rainscreen implies mechanical fixing, but no source confirms it. | Unclear → conservative branch (yes, diesel). |
| 14 | A4 · T2 | Evidence for "made in country X" is often an old trade-press article (I-PAN Italy, 2013; Swiss Krono France, 2017). The protocol sets no recency requirement. | Accepted them with links. I-PAN's current OSB production is not re-verified. |
| 15 | STEP 3 | (a) It is not said whether "our value" is computed on base ecoinvent or with the premise 2050 scenario. (b) Some ÖKOBAUDAT datasets give inconsistent densities (the Schönthaler 430 dataset lists gross density 405; Egger's flow name says 607 but the property says 611). | (a) Base ecoinvent 3.12 cut-off, EF v3.1 `climate change: fossil`. (b) Used the declared density in the dataset name for Schönthaler (430) and the gross-density property for Egger (611). |
| 16 | STEP 3 category | "The product's category" is easy for OSB but not obvious for cork. ÖKOBAUDAT has "Expanded cork" under insulation and "Cork slab" under wood floors. | Used *Dämmstoffe / Expandierter Kork* to match EN 13170. |
| 17 | END | The protocol says to save into `data/baseline_recipes/` under git, but the run prompt says `runs/<run_id>/`. | Followed the run prompt. |
| 18 | C3–C4 note | The revised NMD scenarios (Nov 2026) in the Excel file were not read. | Used the category shares as printed in the protocol table. |

Access problems that affected the search: the Arrigoni et al. 2017 hempcrete LCA (unibg.it, polimi.it) and scientific.net returned HTTP 403, and bcork.amorim.com did not resolve. With those sources, hempcrete processing energy and cork fixing could have been answered from a primary source.
